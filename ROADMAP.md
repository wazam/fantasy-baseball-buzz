# Roadmap

## Proposed Features

Collected ideas for future development. Not actively planned or prioritized.

1. **Roster % Tracking** -- Monitor player roster percentages across all major platforms.

2. **Expanded Roster Imports** -- Support importing league rosters from Yahoo, CBS, Fantrax, and NFBC using `LEAGUE_LOGIN_EMAIL`.

3. **Historical Trend Analysis** -- Analyze changes in player value over time using archived JSON payloads.

4. **Automated Scraping Schedules** -- Run scraping jobs automatically on a schedule instead of triggering them manually.
